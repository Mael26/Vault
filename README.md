# VAULT — Almacén de ideas

Notes app fullstack.

## Stack
- Backend: Java 21, Spring Boot 4.1
- Frontend: React 19, TypeScript, Vite
- Database: PostgreSQL

## Quick Start
```bash
docker-compose up -d
# Backend: java -jar target/vault-api.jar
# Frontend: cd frontend && npm run dev
```

## Fases
- Fase 1: CRUD notas
- Fase 2: Categorías
- Fase 3+: Usuarios, búsqueda, tags
